# Edge Esmeralda public models

Stable URLs for the GLB assets the app uses. Drop these into any
other 3D pipeline — Blender, Three.js Editor, Hugging Face / Reachy
tooling, a different agent, etc.

## Vibey (canonical)

The robot character you see as Vibey 2.0 in `/space`, the memory
garden, the gallery, and disco mode.

- **URL:** `/models/vibey.glb`
- **Public:** `https://edgeesmeralda.lovable.app/models/vibey.glb`
- **Size:** 453 KB
- **Origin:** Three.js example *"Robot Expressive"* by Tomás Laulhé
  and Don McCurdy. Released CC0.
- **Animations:** `Idle`, `Walking`, `Running`, `Dance`, `Sitting`,
  `Standing`, `Wave`, `Yes`, `No`, `ThumbsUp`, `Punch`, `Jump`,
  `Death`
- **Morph targets:** `Angry`, `Surprised`, `Sad`
- **Recommended display height:** ~1.6 m

## Expressive Vibey (alt / heavier)

The earlier, chunkier Vibey model. Higher poly, different aesthetic
— preserved here for anyone who prefers the heavier look.

- **URL:** `/models/expressive-vibey.glb`
- **Public:** `https://edgeesmeralda.lovable.app/models/expressive-vibey.glb`
- **Size:** 12.4 MB
